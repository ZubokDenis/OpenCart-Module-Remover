OpenCart Module Remover – Удалить модули из админ-панели

Удобный модуль для OpenCart, который добавляет кнопку удаления модулей прямо в админ-панели, 
не требуя доступа к файлам сервера.

## Проблема
OpenCart не предоставляет встроенного способа удалить установленные модули. Это вынуждает 
администраторов вручную удалять файлы модулей через FTP или SSH, что неудобно и чревато ошибками.

## Решение
Модуль добавляет кнопку удаления на страницу "Расширения → Модули" и позволяет удалять 
модули одним кликом прямо из админ-панели.

## Особенности
✓ Простой интерфейс удаления модулей  
✓ Удаление всех файлов модуля за раз  
✓ Безопасное удаление только необходимых файлов  
✓ Поддержка OpenCart 3.x  
✓ Совместимость с модулями в виде OCMOD  

## Установка
1. Скачайте архив модуля
2. Распакуйте содержимое в корень OpenCart
3. Перейдите в Админ → Расширения → Модули
4. Найдите модуль и установите его
5. Теперь на странице модулей появится кнопка удаления

## Использование
На странице "Расширения → Модули" в каждого установленного модуля появится кнопка "Удалить".
Нажмите её для удаления модуля и его файлов.
